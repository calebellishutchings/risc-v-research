01 · Porting record

PicoRVD on Pico 2 RISC-V

The port moves from the original Pico/Linux assumptions to a Pico 2 RISC-V, Windows, SDK 2.x workflow. The key work is USB transport migration, PIO timing recalibration, robust flash sequencing, and GDB detach behavior.

CoreMark on CH32V003

CoreMark’s upstream workload files remain unmodified. A separate bare-metal port layer provides the timer, UART output, watchdog service, and target-specific build settings.

Reporting note. This result is a project-specific CoreMark-derived measurement, not an official CoreMark score. The port uses a 1,200-byte static data block instead of CoreMark’s standard 2,000 bytes, and the captured run reports that its CRC cannot be validated for its seed values.

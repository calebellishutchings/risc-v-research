Comparative implementation and performance analysis of RISC-V systems

This independent study examines how RISC-V systems are brought up, measured, and compared across an FPGA platform and the RP2350 embedded platform. RISC-V is an open instruction-set architecture: a shared specification for the instructions a processor can execute.

This site records the project’s technical progress. Its current entry documents a Windows-based PicoRVD port and a CH32V003 performance experiment.

Current technical record

PicoRVD and CH32V003

The first documented experiment adapts PicoRVD, a USB debugging and programming tool, for the Raspberry Pi Pico 2’s RISC-V environment on Windows. It then uses that workflow to build, program, and time a CoreMark-derived workload on the CH32V003, a small RISC-V microcontroller.
